# Elevate Entry Root Picker to Page Header

The entry root directory selector was previously embedded as Step 1 inside the left-side scan scope panel, crowding the machine list and creating unnecessary vertical scrolling. We elevated entry root configuration to the right side of `PageShell`'s sticky header, aligned opposite the category title, while adapting responsive widths to Radix Themes `md ~ lg` breakpoints to comfortably support both 14-inch laptops (1024px–1280px logical viewport) and 23-inch desktop monitors (1920×1080).
