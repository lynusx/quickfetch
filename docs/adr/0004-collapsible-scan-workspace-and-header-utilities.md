# Collapsible Scan Workspace and Header Utilities

We evolved the stacked scan workspace (ADR-0001–0003) into a collapsible two-phase layout across all four scan categories (EL, LXT, PL, AOI) to maximize first-screen visibility on 14-inch laptops while keeping Radix Themes As-Is purity. Low-frequency page utilities—the Entry Root selector and Scan History—now live in `Page Header Actions` as a compact path button (opening an anchored `Popover`) and a history trigger (opening a right-side `Drawer` with `AlertDialog` clear confirmation), while an unconfigured or zero-machine Entry Root renders a single optically centered setup card (vertically and horizontally centered in the remaining viewport while hiding the redundant header Entry Root trigger until setup completes or a history task is restored) instead of empty parameter matrices. During configuration, the expanded `Scope Parameter Matrix` drops legacy step badges and owns the primary「开始扫描」footer CTA without rendering an empty task card below; once a scan starts or history is restored, it collapses into a single-row `Scope Summary Bar` so the `Single-Column Task Stream` can scroll naturally with `PageShell` and anchor its local copy controls (including partial-failure retry and `AlertDialog` overwrite confirmation) as a sticky bottom bar.
