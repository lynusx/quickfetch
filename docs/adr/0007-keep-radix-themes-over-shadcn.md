# Keep Radix Themes Over Migrating to shadcn/ui

We evaluated migrating the renderer UI from `@radix-ui/themes` back to `shadcn/ui` (Tailwind CSS + Radix Primitives) and decided to stay on `@radix-ui/themes`. QuickFetch is a focused offline desktop utility built around forms, tables, dialogs, and settings—`@radix-ui/themes` covers nearly all of its UI primitives natively across 51 TSX files with only 19 small CSS files (~754 lines total), backed by existing `AGENTS.md`, `stylelint`, and `radix-themes-best-practices` guardrails. Migrating back to `shadcn/ui` would incur a full 51-file rewrite and ongoing Tailwind/`components/ui/*` maintenance with no direct user-facing benefit; when a component is absent from `@radix-ui/themes`, we integrate headless libraries (such as `react-day-picker`, `sonner`, or `@tanstack/react-table` if ever needed) styled with Radix Themes design tokens.
