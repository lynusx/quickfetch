# App Shell Proportions, PageShell Alignment, and Three-Tier Content Widths

We keep the dedicated `40px` window topbar (`--app-topbar-height`) instead of extending the sidebar to the top edge of the window so Windows `titleBarOverlay` controls, drag regions, and below-topbar modal/drawer overlays (`Dialog`, `AlertDialog`, `Drawer`) stay collision-free with page-header utility actions. To reclaim vertical space on 14-inch screens without losing that stability, we remove the extra `24px` top padding above `PageShell`'s sticky header, tighten `--app-page-header-height` to `56px`, narrow `--app-sidebar-width` from `242px` to `216px`, and remove the decorative static "本地运行" indicator from the sidebar footer (keeping only version and update status).

Inside `PageShell`, the sticky frosted backdrop and bottom divider remain full-bleed across the content surface, while the inner header row shares the same `contentMaxWidth` and horizontal centering (`mx="auto"`) as the page body so titles, header actions, and cards stay vertically aligned on 23-inch monitors. Pages adopt three explicit `contentMaxWidth` tiers matched to their layout shape: `1120px` for single-column scan workspaces (EL, AOI, LXT, PL), `1360px` for the two-column Excel parser (left filter sidebar + wide preview table), and `760px` for the single-column Settings page.

To align remaining legacy views with this unified scale, the Excel parse page drops its redundant 4-step guide card in the empty state (moving usage notes into the header `HelpTip`), collapses the uploaded state's duplicate dropzone + file-meta panels into a single compact drag-replaceable file status bar above the two-column workspace, and upgrades its tables, buttons, and metadata to `size="2"`, matching Settings (`SegmentedControl` upgraded to `size="2"`) and the scan pages.
