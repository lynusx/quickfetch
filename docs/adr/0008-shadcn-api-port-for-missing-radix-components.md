# Port shadcn/ui Composable APIs for Missing Radix Themes Components

When QuickFetch needs a UI component not provided by `@radix-ui/themes`, we check `shadcn/ui` first and port its composable component API and headless primitives into `src/renderer/components/<name>/` using `@radix-ui/themes` primitives and design tokens—without introducing Tailwind CSS. Under this convention, we replaced our custom implementations with four ported component families: `Drawer` (Radix `Dialog`-backed right/left/bottom slide-over, now hosting `HistoryPanel` from the right edge), `Empty` (`Empty`/`EmptyHeader`/`EmptyMedia`/`EmptyTitle`/`EmptyDescription`/`EmptyContent`, replacing `EmptyState`), `Calendar` + `DatePicker` (splitting `react-day-picker` into a standalone `Calendar` composed inside `DatePicker`), and `Sidebar` (`SidebarProvider`/`Sidebar`/`SidebarMenu`/`SidebarInset`/`SidebarTrigger` with collapsible icon-rail mode and `Ctrl+B` shortcut, replacing the custom `AppSidebar` layout).
