# Single-Column Vertical Scan Scope Form

We replaced the 3-column `Scope Parameter Matrix` layout with a single-column vertical form flow across all four scan categories (EL, LXT, PL, AOI) to eliminate horizontal crowding and uneven column heights. Frequently adjusted time controls—paired Date/Shift and time slots—sit at the top of the card so their vertical position stays stable regardless of machine count, followed by plant/machine selection (with AOI side/image kind), PL levels, and defect types directly above the「开始扫描」footer CTA. All scope fields—including plant, machines (sorted in natural ascending order by name with `LX` machines placed last, rendered as borderless fixed-width `128px` grid items inside a `180px`-capped `ScrollArea` with hover `Tooltip` showing the machine's absolute UNC path up to its fixed identifier or share, and auto-selecting all non-`LX` machines on initial load and plant switch while preserving explicit select-all), shift, PL levels, time slots, defect types, and AOI side/image kind—now render via a borderless `layout="inline"` mode on `ChoiceRadio` and `ChoiceList`. Every multi-select field merges select-all and clear into a single toggle action (`全选` / `清空`, or `全选本区` / `清空本区` for machines), with a `200px` search input placed inline inside the machine `Field` header alongside `variant="soft"` `size="2"` toolbar actions; typography and control sizes across the scope form and results table align with the settings page (`Heading size="3"` panel titles, `Text size="2"` field labels/options/table cells, and default `size="2"` checkboxes, radios, and buttons). To keep left labels and right toolbar actions within a comfortable eye span on 23-inch monitors while keeping the scope card and results table aligned, all four scan pages constrain `PageShell` to `contentMaxWidth="1120px"`.
